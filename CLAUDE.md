# take_recorder

## Seguimiento (RAMonitor)

This project is tracked in `ramaguirre/ramonitor`, file `projects/take-recorder.md`.

- End every session with a clear commit or PR message: what changed, what is next, and
  what needs the director.
- A daily catch-up updates RAMonitor from those messages.
- This repo is public: no local paths or confidential data in commits, messages or files.
